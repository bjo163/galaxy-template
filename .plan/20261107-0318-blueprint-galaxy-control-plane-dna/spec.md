# Specification

## Product direction

**Identity:** Galaxy is a quiet mission control for teams building data products on Arsy.

The interface should help a user understand the path from workspace to project to model to records, then act on that scope. Galaxy's space reference is structural: connected systems and clear scopes. It is not a request for sci-fi decoration.

## Requirements

- REQ-001: Replace visible Vuexy template identity with Galaxy product identity in the shared authenticated shell.
- REQ-002: Make workspace/project context and the user's current location easy to scan.
- REQ-003: Prefer useful tables, activity, and scoped actions over generic KPI-card grids where the product data supports them.
- REQ-004: Use restrained ink, mineral, and signal-green colors; keep semantic status colors distinct from brand accent.
- REQ-005: Keep light and dark themes usable with accessible contrast and visible keyboard focus.
- REQ-006: Preserve responsive navigation and allow dense builder workflows to reflow at mobile widths.
- REQ-007: Keep the first redesign focused on the shared shell, login/onboarding, and genuine Arsy workflows; exclude unrelated Vuexy demo applications.

## Design dials

- ENERGY: 2/3 — confident product presence, restrained and practical.
- RHYTHM: 2/3 — a consistent shell with occasional composition changes for overview, tables, and setup flows.
- MOTION: 1/3 — fast state transitions and clear feedback; no decorative choreography.

## Acceptance

The UI reads as Galaxy even when the wordmark is hidden; workspace and project scope are apparent; the visual system serves the actual builder tasks; both themes and mobile layouts remain supported; no fictitious data or claims are introduced.
